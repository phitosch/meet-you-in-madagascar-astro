# meet-you-in-madagascar-astro

## Run locally with Docker

This repository contains the generated static site. Start it with Docker Compose:

```sh
docker compose up --build
```

Open [http://localhost:8080](http://localhost:8080). To stop the site, press `Ctrl+C`; to run it in the background, use `docker compose up --build -d` and stop it with `docker compose down`.
